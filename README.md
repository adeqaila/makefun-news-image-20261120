# The World in One Day — 20 November 2026

Entry for the make.fun [news-image-20261120](https://make.fun/bounty/news-image-20261120) bounty: sum up 20 November's world news in one image.

36 numbered stories on a single 1024×1024 front page: 3 hero stories (Cyclone Akvan makes landfall in India — 300,000 evacuated; the Shenzhen three-presidents declaration; the ICJ genocide verdict on Myanmar), 9 panels, a region bar, a hard-number stat strip, numbered map pins, an ALSO list (13–36), an honest DATE CHECK box, and a BY THE CLOCK strip (UTC).

`entry.png` is the front page (JPEG bytes under the required name, as the rules allow). `main.ts` (Node 22, stdlib only, no network) checks the image against the competition gate and writes it unchanged to the output directory, so repeated grader runs produce byte-identical output.
